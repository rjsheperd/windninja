* Conventions
- *Tests*:
  - Unit tests are Boost.Test cases in =autotest/= and are added to =test_main=.
  - Each case is registered with =add_test(<suite>_<case> ... --run_test=<suite>/<case>)=,
    matching the existing =autotest/CMakeLists.txt= style.
  - CLI integration tests are =.cfg= files under =autotest/config/pass/=.
- *Golden comparison*: compare to the OpenFOAM-11 reference outputs from
  Phase 0. The metrics are:
  - speed: RMSE and max abs diff, in m/s;
  - direction: circular mean abs diff, in degrees;
  - k: relative RMSE.
- *Tolerances*: placeholder values are marked =TBD=. They need sign-off from
  the WindNinja science team before Phase 2 ends.
- *Gates*: =GATE= headings are go/no-go decisions. Don't start the next phase
  until the gate is recorded as DONE or CANCELLED, with a note.

** DONE 0.3 Golden-case dataset [9/9]
Note: the CLI writes no ASCII k grid (turbulence only goes to KMZ). The golden
u, v and k come from the case directory's =foam.tif= instead: Float64 bands
u, v, k (m/s, m²/s²) sampled on the output-height surface. That's the raw
solver output, before any WindNinja post-processing. Caveat: when the first
cell is taller than the output height (true for every case: see Result),
sampling uses =cell= interpolation, so these are *ground-cell* values.
WindNinja log-profiles them down to the output height afterwards
(=SampleRawOutput=, =ninjafoam.cpp:2742=). =metadata.txt= records
=first_cell_height_m= and =output_height_resolved=. The CLI =*_vel.asc= /
=*_ang.asc= are kept as the true output-height product.

Result (2026-10-20, macOS arm64, OpenFOAM-11, 2m46s for 8 cases, 3.9 MB):
- Two full runs were bitwise identical (max |diff| 0 across u, v, k, vel, ang).
- No retries on any case. =mackay_small= does *not* trigger the DEM-smoothing
  retry, so the retry path still has no golden case.
- One refinement round everywhere, so the first cell equals the mesh resolution:
  59 m (flat), 63 m (medium), 80 m (coarse), 286 m (Mackay). The 20 ft output
  height is never resolved. The momentum output at 20 ft is a log-law
  extrapolation from ground-cell centres about 30–140 m AGL, and a new backend
  must reproduce that post-processing step too (Phase 2.4).
- The first-cell height is derived from =log.ninja= (=meshResolution=,
  =nRoundsRefinement=) using the code's formula, checked against
  =finalFirstCellHeight= debug output for one case.
- An earlier run that seemed to take 16 minutes was the laptop sleeping, not a
  slowdown.

** DONE 1.2 Extract =OpenFoamBackend= [8/8]
Approach: extract-class-by-delegation. =OpenFoamBackend= holds a
=WindNinjaInputs&=, so the OpenFOAM method bodies move almost verbatim, and
only the boundary (=simulate_wind=, =SampleRawOutput=) is rewritten. The log-
profile correction in =SampleRawOutput= (=ninjafoam.cpp:2742=) is WindNinja
post-processing that every backend needs (see 0.3), so it stays on the
WindNinja side. =MomentumResult= therefore gains the sample height and a
resolved flag.
Boundary map (from =ninjafoam.h= / =ninjafoam.cpp=):
- Moves to the backend: case files (=WriteFoamFiles=, =Write*Files=,
  BC blocks, =SetInlets= / =SetBcs= / =ComputeDirection=), mesh
  (=writeBlockMesh=, =SetBlockMeshParametersFromDem=, =MoveDynamicMesh=,
  =RefineSurfaceLayer=, =TopoSet=, =RefineMesh=, =RenumberMesh=), solve
  (=ApplyInit=, =DecomposePar=, =SimpleFoam=, =ReconstructPar=, retry loop),
  sampling (=Sample=, =SanitizeOutput*=, =SampleCloudGrid=, raw read in
  =SampleRawOutput=, probe I/O =writeProbeSampleFile= / =runProbeSample= /
  =readInProbeData*=), case reuse (=UpdateExistingCase=, =GenerateNewCase=,
  =Read/WriteNinjaLog=, =CheckForValidCaseDir=, =Get*OnDisk=) and their state
  members.
- Stays in =NinjaFoam=: =simulate_wind= setup (=CloudGrid=, =init=,
  =keepOutputGridsInMemory=), the log-profile parts of =SampleRawOutput= and
  =fillEmptyProbeVals= (use =init->=), =generateMassMesh=,
  =generateColMaxGrid=, output resolution, file names and writers, and
  =countNumCores= / =set_numberCPUs=.
- =checkCancel()= is called inside the pipeline (MoveDynamicMesh, SimpleFoam
  loop, GenerateNewCase), so the backend holds a =checkCancel= callback member.
- NinjaFoam is copied by armies (copy ctor / =operator==), so the backend is a
  per-run local inside =simulate_wind=, not a member holding =WindNinjaInputs&=.
- =pszFoamPath= is static and set by =ninjaArmy= via =GenerateFoamDirectory= /
  =SetFoamPath=. NinjaFoam keeps those as forwarding statics.
